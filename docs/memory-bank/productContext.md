# Product Context

## What This Project Is
A completed thesis codebase that predicts music attributes from multimodal features:
- Valence
- Energy
- Danceability
- Popularity

## Current Objective
Use Semester 2 deep learning experiments to test whether neural approaches can close or beat Semester 1 ML baselines.

## Baseline Reality
- Strongest baseline remains gradient boosting for tabular engineered features.
- Deep learning currently narrows gaps but does not fully surpass ML except near-parity on popularity.

## Success Definition (Current)
1. Achieve consistent gains over Phase 1B average R2 (0.4405).
2. Reduce ML gap on valence/energy/danceability with reproducible experiments.
3. Keep outputs publication-ready: clear ablations, stable metrics, and defensible methodology.
