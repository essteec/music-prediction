# Project Brief

## Title
Music Attribute Prediction from Multimodal Features

## Scope
Predict four targets (valence, energy, danceability, popularity) on 550k+ songs using engineered features and deep learning extensions.

## Current Snapshot
- Baseline ML work: complete.
- Deep learning extension: complete.
- Final tuned models: CatBoost (ML) and AttentionTaskGatedFusionMLP (DL).
- Live Gradio app serves both models on the 4,254-feature thesis input space.

## Why This Matters
- Quantifies which modalities help each musical attribute.
- Tests when deep learning helps beyond strong tabular ML baselines.
- Produces reproducible research artifacts (models, metrics, notebooks).
